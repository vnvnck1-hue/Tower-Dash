# TowerClimb — 무한 나선 계단 러너 (Godot 4.7, Forward+)

레퍼런스 일러스트(`reference/ref.webp`)의 구도·색·툰 쉐이딩을 Godot 로 옮긴 환경 프로토타입.
카메라와 조명은 고정, 월드가 "스크류 운동"을 하며 끝없이 탑을 오르는 것처럼 보인다. 붉은 두건의 주자 캐릭터가 리미티드 애니메이션으로 달리고 공격·점프·대쉬한다.

## 실행
Godot 4.7 에서 프로젝트를 열고 실행(F5). 혹은 CLI:

```bash
Godot_v4.7.2-stable_mono_win64_console.exe --path . 
```

스크린샷 / 시퀀스 캡처 (렌더링 검증용):

```bash
Godot_v4.7.2-stable_mono_win64_console.exe --path . -- --shot=screenshots/final.png --frames=40 --phase=0.0
```

```bash
Godot_v4.7.2-stable_mono_win64_console.exe --path . -- --seq=screenshots/seq:45:12
```

## 조작
| 키 | 동작 |
|---|---|
| A / D (← / →) | 등반 속도 감소 / 증가 (0.5x ~ 2.2x, 놓으면 1.0x 로 복귀). 자동 전진. (2026-10-28 좌우 자유 이동·뒤돌기 시도는 "앞으로 잘 안 가고 미끄러진다"는 피드백으로 롤백) |
| F1 / F2 / F3 | 카메라 소프트 팔로우 프리셋 Light / Medium / Strong |
| 1 / 2 / 3 | 대쉬 모션 블러 프리셋: 방향성 소프트 / 캐릭터 중심 방사형 / 방향성(캐릭터 선명) |
| Space | 점프 (11프레임 @8fps). 공중에서 한 번 더 누르면 더블 점프(앞구르기 턱 플립) |
| J / 마우스 왼쪽 | **카타나 제로식 발도** — 커서 각도(±85°, 전방만)로 베기를 조준한다. 검기 원호·팔·상체·머리가 그 각도로 기울고, 판정은 조준 각 ±70° 안의 적만(2.4 이내는 전방향). 베는 방향으로 미끄러지며(앞 성분 런지, 위 성분 홉) 선딜레이 없이 첫 프레임부터 판정, 0.08초부터 캔슬. 공중에서는 air_attack |
| 마우스 오른쪽 | 슈리켄 투척 — 마우스 방향으로 직선 비행, 닿은 적 즉사. 최대 3개, 1초에 1개 충전(하트 아래 별 아이콘) |
| F11 / Alt+Enter | 전체화면 ↔ 창 모드 전환 (시작은 전체화면, `project.godot` `window/size/mode=2`) |
| K / Shift | 전방 도약 대쉬 (앞으로 살짝 뛰어오르며 월드 속도 smoothstep 1.85x 버스트) |

## 캐릭터 (scripts/character.gd)
- 절차적 박스 리그: Root → Hips → Torso → Head / 팔(상·하·손·칼) / 다리(상·하·부츠) / 망토 3마디. 관절 피벗 노드에 메시를 매달아 회전이 관절에서 일어난다.
- **리미티드 애니메이션**: 모든 클립은 `Animation.INTERPOLATION_NEAREST` 로 키 포즈를 홀드한다(중간 프레임·이징 없음). 달리기 8fps 4포즈 루프, 공격 12fps(예비 1 / 스매시 1 / 팔로스루 3), 점프 8fps(스쿼시 → 스트레치 → 정점 홀드 → 낙하 → 착지 스쿼시 → 복귀), 대쉬 8fps(예비 1 / 런지 홀드 3 / 복귀 1).
- 포즈는 `_add_pose(anim, tracks, time, {관절: 회전도, "@관절": 위치})` 딕셔너리로 작성한다. 과장(스쿼시·스트레치, 큰 보폭, 망토 휘날림)은 포즈 값에서 조절.
- 캐릭터는 카메라 공간에 고정(탑 정면, 레인 반경)되고 발은 현재 아래를 지나는 디딤판 높이를 따른다(`_tread_y_under_runner`). 월드가 아래로 흘러가므로 "달리는" 것처럼 보인다.
- 데모/검증 플래그: `-- --anim=run|attack|jump|dash|cycle` (동작 반복), `-- --charcam` (근접 카메라), `--seq` 와 조합해 시트 캡처.

## 전투·목숨 (scripts/goblin.gd, scripts/hearts_hud.gd, main.gd `_update_combat`)
- **진행 좌표**: `progress`(되감기 없는 누적 계단 수). 적·화살은 절대 계단 번호 `k_abs` 를 가지며 `_step_local()` 로 월드 로컬 위치(해당 턴의 디딤판 높이)에 놓인다. 스폰은 1.2바퀴 앞까지 9~16계단 간격, 끊긴 계단 ±3 제외.
- **무리 스폰**: 7~12계단 간격으로 3~6마리가 2~4계단 구간에 겹쳐 스폰되고, 각자 좌우 오프셋(계단 폭의 ±36%)·달리기 속도(4.2~6.5계단/초)·돌진 거리(11~17계단)·팔 휘두르기 위상이 랜덤이라 줄 서지 않고 몰려 내려온다. 크기 `size_scale` 1.6 × 0.7~1.3 랜덤(±30% 변주, 화면상 플레이어와 비슷). **주의**: 배치 시 `_step_local()` 이 Transform3D 전체를 다시 쓰므로 `g.scale` 대신 `size_scale` 을 `scaled_local()` 로 매 프레임 구워 넣는다(이전에는 스케일이 매 프레임 1.0 으로 덮여 크기 변경이 전혀 반영되지 않던 버그).
- **돌진**: 플레이어가 돌진 거리 안에 들어오면 `charge` 상태로 계단을 뛰어 내려온다. 포즈는 양팔을 머리 위로 풍차처럼 휘두르고 다리를 크게 차는 우스꽝스러운 달리기(`_run_pose`), 대기 중엔 조급하게 깡충거림. 3.2계단 안에 오면 0.45초 예비 → 휘두르기, 빗나가면 다시 돌진.
- **근접 고블린**: 돌진 후 예비(곤봉 뒤로) → 휘두르기. 휘두를 때 2.4계단 안·지상·무적 아님이면 피격. 부딪혀도 피격.
- **궁수 고블린**: 7~16계단 거리에서 draw1(1.5초) → draw2(1.5초, 몸을 뒤로 젖히고 시위 손이 머리 뒤로 가는 과장 포즈 = 패링 텔) → 발사. 7계단 안으로 들어오면 활을 든 채 함께 돌진해 근접 공격. 화살은 초당 11계단으로 내려오며, 0.6계단 안에서 공격 활성 프레임이면 **패링**(불꽃 + 속도 버스트), 점프 높이 2.2 이상이나 대쉬면 회피, 아니면 피격.
- **대검**: `reference/sword_ref.png` 디자인(넓은 날·어두운 풀러·천 감은 리카소·고리 폼멜), 날 길이 2.6. 검기 원호 반경 1.2~4.8, 중심 1.4~1.5 전방, 타격 범위 −0.6~5.2계단.
- **내려찍기(slam)**: 공중에서 S/↓ + J. 살짝 뛰어오르며 한 바퀴 돌아 0.30초에 검이 디딤판에 꽂힘 → 전방 5.5계단 범위 전부 처치, 충격파·섬광·히트스톱.
- **혈흔**: 처치 지점에서 탑 벽면으로 3~6개의 초록 데칼(랜덤 크기·회전·4종 텍스처)을 투영, 최대 90개 유지.
- **랜덤 런치**: 방향(수평 −9°~+60°, 깊이 ±), 세기 0.55~1.6배(거리·높이·지속시간), 3축 랜덤 스핀.
- **멀티킬**: 0.35초 안에 3킬 이상이면 강타 버스트(크기 ×1.3). 슬로모션은 삭제됨. 엔진 시간 자체가 느려져 월드·포즈·FX 가 프레임 드롭 없이 연속적으로 느려지고, 렌즈 왜곡이 함께 들어간다.
- **처치**: 공격 활성 프레임(0.03~0.26초)에 −0.6~5.2계단 안의 적은 한 방. 연출(`_kill_goblin`, 사양: `reference/hit-effects-spec.md` 를 우리 게임에 맞춰 적용): 16ms(1프레임) 히트스톱, 진행 중 재발동 없음 → 카메라 펀치 → **MISFITZ 별 버스트**(`scripts/hit_burst.gd`, 모든 버스트를 ImmediateMesh 하나에 매 프레임 다시 그림, 최대 24개): 0~0.033 팝(0.55→1.12, 흰→테두리, 흰 섬광 원) → 0.033~0.10 정점(두툼한 3갈래 비대칭 별, 잔상 2겹, 뒤 덩어리, 광선 4, 픽셀 조각 11) → 0.10~0.17 가지가 선으로 가늘어지고 덩어리가 파편 3개로 → 0.17~0.30 축소·소멸. 팔레트는 MISFITZ 근접(면 #f8d2fa·테두리 #ff2ee8·베벨 #c214d6·뒤 #9b2cf0·파편 #7f46dc), 패링은 원거리 노랑 톤. 강타(내려찍기·멀티킬)는 시간 ×1.25·크기 ×1.3·잔상 3겹·조각 16. 버스트 위치는 적 표면(공격 온 쪽, 폭×0.4)에서 카메라 쪽 0.25 당김. 함께 **화면 굴절 링**(`shaders/distortion.gdshader`, 22px/800px, 색수차) + 녹색 파편 + 적 스쿼시(1.22, 0.84, 1.22). 공격마다 발밑 마젠타 바닥 원(α0.1, 0.2s). 내려찍기는 마젠타 바닥 충격파(4.4/0.25s) + 굴절 7.2. 검기 원호는 꼬리 #b72c8f → 몸체 #ff3cbd → 머리 흰색×1.2 → 흰색으로 변한 적이 스쿼시 후 오른쪽 위로 0.5초 포물선 회전 날아가며 40ms 간격 잔상 3~7개. 런치·링·스트릭·잔상은 `_fx` 리스트에서 게임 델타로 구동되어 히트스톱에 함께 멈춘다. `--slowkill` 플래그(캡처용)는 처치 시 0.7초 슬로모션.
- **목숨**: 3개(우상단 하트, 잃을 때 팝). 0이 되면 GAME OVER 표시 후 3개로 리셋.
- **추락**: 끊긴 계단에 지상 상태로 오면 하트 −1, `hang` 클립(난간에 매달림, 다리 흔들림)으로 월드 정지. Space → `recover`(위·뒤로 높이 떠올라 체공 후 착지) + 속도 버스트로 구멍을 넘고 1초 유예.
- **피격**: 적에게 맞으면 **한 층(나선 한 바퀴) 아래로 떨어진다** — `knock`(0.26초, 뒤로 밀려 디딤판 밖으로) → `plunge`(0.62초, 허우적대며 추락; 이 동안 `ClimbWorld.fall_offset` 이 0 → PITCH(24) 로 가속 상승해 월드가 한 피치 위로 흐름) → 아래층 계단 끝을 붙잡는 `hang` → 0.45초 후 자동 `climb`(0.44초) → 달리기. 나선은 피치마다 반복되므로 붙잡는 순간 `fall_offset` 을 0 으로 되돌리고 `progress -= 64` 만 하면 끊김 없이 "아래층"이 된다(적 거리는 +64, 떨어진 층은 `_spawn_next` 를 당겨 다시 채움). 매달린 동안 Space 는 큰 `recover` 도약. 총 약 1.8초 + 한 바퀴 손해가 피격 리스크. 1.6초 무적(반투명 + 12Hz 깜빡임). `knock`/`hang`/`climb` 중엔 월드 정지, 입력 무시(hang 의 Space 제외). 구멍에 빠진 `hang` 은 자동 복귀 없이 Space 대기.
- **적 배치/방향**: 고블린 모델(Tripo, +Z 정면)은 리그 안에서 180° 돌려 리그 전방 -Z 와 맞추고, `_step_local()` 은 리그 -Z 가 나선 접선 아래 방향(플레이어 쪽)을 보도록 `Basis(UP, a + π/2)` 를 쓴다. 화살은 같은 프레임을 +90° 돌려 +X 가 비행 방향. 돌진 중 1.2~2.8초 간격으로 가끔 도약(`_update_hop`, 높이 ~1.2, 이동 1.35배).
- **처치 연출(갱신)**: 흰색 런치는 삭제. 몸이 즉시 뼈(흰 막대 1/3)·살(초록 덩어리) 8~11개 파편으로 터져 베인 방향(적의 뒤쪽)으로 ±40° 부채꼴·7~13 속도로 튀고, 중력(−26)·텀블링으로 계단을 지나 탑 아래로 떨어진다(충돌 없음, 카메라 30 아래에서 제거, `_spawn_gibs` / fx "gib"). 별 버스트는 노란 톤(`HitBurst.MELEE`), 보라 원·파편 삭제, 가장 큰 살덩이를 따라다님(`spawn(..., follow)`). 검기는 푸른색(#3cb8ff/#2c5fb7), 띠 두께가 검신 폭만큼(안쪽 반경 0.8, 셰이더 band 0.35~0.92).
- **양방향 전투**: 적 AI 는 부호 있는 거리의 절댓값으로 동작하고 항상 플레이어 쪽으로 돌진(`sdir`), 플레이어 아래의 적은 배치 시 180° 돌려 위를 본다. 화살은 발사 시점의 방향(`arrows[i][2]`)으로 날아간다. 캡처 플래그 `--anim=back`(뒤돌아 내려감), 데모 중엔 커서를 무시하고 정면 베기(`demo_aim`), `--aim=x,y`(뷰포트 픽셀)로 커서 위치를 고정해 조준 발도를 검증(`screenshots/aim_up|down|back` 으로 위·아래·뒤쪽 확인됨). `--anim=mouse` 는 실제 OS 커서를 `Input.warp_mouse` 로 캐릭터 주변 6방향에 옮기고 왼쪽 클릭 `InputEvent` 를 주입해 진짜 입력 경로(`_unhandled_input` → `do_action` → `_aim`)로 발도를 검증한다. `log.csv` 끝 열에 커서 방향·facing·phi·실제 마우스 좌표가 기록된다(2026-10-28 결과: 오른쪽 phi 0 / 우상 45 / 위 85 / 왼쪽 facing −1 / 우하 −45 / 좌상 facing −1·45 — 모두 일치). 공격 홉은 카타나 제로 자료(나무위키: "위를 향하면 공중에서 활공, 이어지는 두 번째 휘두르기의 상승은 매우 짧아 무한 비행 불가") 대로 지면에서 1회 활공 + 이후 2회 짧은 상승(35%)까지만. 공격 전체 길이 0.2초(12프레임)는 스피드런 가이드의 "롤 → 10프레임 뒤 베기 → 12프레임 뒤 롤" 리듬과 맞춘 값.
- **적 밀도**: 무리 2~5마리, 8.5~13.5계단 간격.
- **체공 중 공격 1회**(`_air_attacks`), 착지 시 리셋. 매달림(`hang`)·피격(`hurt`) 중에는 공격·대쉬·점프 입력이 무시되고 매달림은 Space 로만 `recover`.
- **규칙 테스트 플래그**: `--anim=airspam`(점프 후 매 프레임 공격 입력), `--anim=hangspam`, `--anim=hurtspam` + `--seq` 로 캡처하면 `log.csv` 에서 상태 전이를 확인할 수 있다. 결과: 체공당 공중 공격 정확히 1회(19회 반복), hang→recover 외 전이 없음, hurt→run 외 전이 없음.

## 디버그 설정창 (F10 또는 `)
Tab 은 패널 버튼이 포커스를 가지면 GUI 포커스 이동에 먹혀 토글이 안 되던 문제가 있어 F10 / ` 로 바꾸고 `_input` 에서 처리한다.
- **Draw slash** 그룹: 발도 강도 프리셋 Subtle(런지 10·상승 6.5·조준 ±70°) / Katana Zero(15·9·±85°, 기본) / Heavy(22·12·±85°). 플레이 중 바로 바꿔 손맛을 비교할 수 있고 `user://settings.cfg` 에 저장된다.
좌상단 패널에 모든 프리셋이 토글 버튼으로 모여 있고 선택된 항목은 노란색 `>` 표시. 선택은 `user://settings.cfg` 에 자동 저장되어 다음 실행에 복원된다. 단축키: F1~F3 카메라, 1~3 블러, 4~6 이징, 7~9 렌즈 왜곡.

## 애니메이션 시스템 (scripts/character.gd)
- AnimationPlayer 대신 **자체 포즈 플레이어**: 클립 = `[시간, 포즈]` 키 목록. 각 키 구간의 앞 22%(`hold_frac`)는 홀드, 나머지는 이징 프리셋으로 보간한다.
- **이징 프리셋** `EASE_PRESETS`: Snappy(1-(1-u)^3.5, 빠르게 치고 정착) / Bouncy(back-out 오버슈트 1.7) / Impact(전반 느린 예비 → 후반 급가속 슬램).
- **딜레이 최소화**: 공격 0.30초, 대쉬 0.36초, 각 클립에 `cancel` 시점(공격 0.16초 등)이 있어 그 이후 입력이면 즉시 다음 동작으로 넘어가고, 그 전 입력은 버퍼링되어 창이 열리는 순간 발동.
- **검기 평면**: 컨트롤러가 매 프레임 전방(계단 위 = 월드 +X)과 카메라 방향을 리그 로컬로 넘기고(`set_frame`), 모든 공격의 원호는 전방 축을 포함하고 카메라 쪽으로 30% 기울인 수직 평면에 생성된다 → 어떤 상태에서도 앞쪽에, 절대 옆에서 보이지 않음. 공중 공격은 높이를 유지한 채 전방으로 베고, 공중 대쉬는 높이를 유지한 전방 도약; 이후 `drop` 클립으로 착지.
- **검증 로그**: `--seq=` 캡처 시 `log.csv` 에 프레임별 동작, 캐릭터 화면 좌표, 공중 높이, 월드 위상, 검기 화면 X, 검기 평면 법선·카메라 내적을 기록한다. 최종 측정: 카메라 3프리셋 × 공격 4종 모두 검기가 캐릭터 앞 +119~+130px, 법선·카메라 내적 0.82~1.00(면으로 보임), 공중 공격 높이 4.3 유지.
- **공격 전진(advance)**: 공격·대쉬가 `_advance_vel` 에 임펄스(9 / 12)를 주고 스프링(강성 14, 감쇠 5.5)으로 0 으로 복귀한다. 컨트롤러가 이 값만큼 캐릭터를 카메라 공간에서 계단 위쪽으로 실제 이동시키고, 카메라는 전진 중 강성을 45% 로 낮춰 뒤늦게 따라붙는다(화면에서 캐릭터가 공격당 약 37px 앞으로 튀어나감). 고블린 크기 1.7배(플레이어와 동일 높이).
- **공격 = 이동**: 모든 공격 키에 Hips 전진 오프셋(0.55~0.7)과 월드 속도 버스트(1.3x, 0.22초). 검기 원호는 `TRAILS` 의 각도 15°→165°(90° = 정면)로 캐릭터 앞을 가로질러 휘둘러진다.
- **도약 대쉬**: `LEAP` 상수 포즈(몸 수평, 양팔·검 전방 직선, 다리 뒤로). 0.05초 만에 도약 포즈, 0.36초에 종료. 월드 버스트 2.1x·0.3초, 버스트 엔벌로프는 `burst_curve`(25% 스냅 인, 75% 탄성 아웃).
- **교차 취소**: 점프 중 대쉬 1회(공중 도약), 대쉬 중 점프(더블 점프 규칙), 점프/대쉬 중 공격(전방 급강하 베기).
- **달리기 기울기**: 등반 속도에 비례해 Hips/Torso 를 앞으로 기울이는 `lean`(컨트롤러가 설정).
- **렌즈 왜곡** `DISTORT_PRESETS`: Off / Wide barrel(k 0.16) / Dynamic fisheye(기본 0.08 + 속도·대쉬에 따라 +0.22). 후처리 셰이더 `distort_k`, `distort_zoom`.
- **탑 셰이딩**: `band_soft`(탑 0.85, 계단 0.35)로 라이트/하이라이트/포커스/림/촛불 밴드를 하드 스텝에서 부드러운 램프로 블렌드. 벽돌은 행마다 랜덤 오프셋·폭(0.6~1.5배)·돌출/함몰(±0.5 깊이)로 불규칙 배치.

## 카메라·캐릭터 조명·트레일
- **소프트 팔로우**: `_update_camera` — 캐릭터 변위(점프 높이·대쉬 런지)와 속도에 따라 목표 위치/주시점/FOV/롤을 계산하고 지수 감쇠로 따라간다. 프리셋은 `CAM_PRESETS` [이름, 위치 게인, 속도 전진, 강성, FOV 게인, 롤°]. `--cam=N` 플래그.
- **모션 블러 프리셋**: 후처리 셰이더 `blur_mode` 0/1/2. 블러는 대쉬와 별도의 느린 램프(`_blur_t`, 0.32초 페이드인 → 0.9초 페이드아웃)에 가우시안 가중 13탭, 최대 0.9~1.4% 화면폭. `--blur=N` 플래그.
- **캐릭터 전용 조명**: 캐릭터 메시는 렌더 레이어 2, `shaders/character_toon.gdshader`(ALBEDO 흰색, light() 에서 색 밴딩, ATTENUATION 으로 자기 그림자). SpotLight3D(cull mask 레이어 2, 그림자 ON)가 캐릭터를 따라다닌다. 주광은 레이어 2 제외. 바닥 그림자는 디딤판에 투영되는 `Decal`(4단 스텝 원형, 공중에서 작아짐).
- **상시 검 트레일**: `_update_ribbon` — 칼 자루/끝 위치를 24Hz 로 스텝 샘플링(7개)해 ImmediateMesh 스트립으로 그림(`shaders/ribbon.gdshader`). 포즈 홀드마다 꺾이는 리듬감. 검 이동량이 임계 이하이면 그리지 않는다.
- **탑 벽돌 틈**: `MeshBuilder.brick_cylinder` — 벽돌마다 전면(랜덤 인셋) + 4개 틈 벽 지오메트리. 틈 윗벽은 위를 향해 라이트 밴드, 아랫벽은 다크 밴드가 되어 그림자 면에서도 틈 질감이 보인다. 뒤쪽 모르타르 베드는 별도 어두운 원기둥.

## 분위기 (키 비주얼 `reference/keyvisual.webp` 기준, PC / Forward+ 전용)
- **창 광선**: `MeshBuilder.ray_wedge` 교차 쿼드 + `shaders/light_ray.gdshader`(가산 블렌드, 길이·폭 페이드, 느린 노이즈). 월드 회전을 따라 창 앵커에 붙고 화면 우측·카메라 앞쪽 창만 켜진다(`_update_rays`).
- **볼류메트릭 포그 / 하층 안개**: Environment volumetric fog(저밀도, 보라 알베도) + 계단 아래 `FogVolume`. 주광은 그림자를 켜 포그 안 광선 형태만 만들고, 표면은 여전히 unshaded 툰 밴딩.
- **포커스 조명**: 셰이더 글로벌 `focus_light`(캐릭터 위치)로 탑 뒤에 4단 푸른 할로. 캐릭터 머티리얼은 포그·조명 제외.
- **촛불**: `shaders/flame.gdshader`(HDR 발광 눈물방울, 6fps 스텝 깜빡임) + 글로우 블룸 + OmniLight(포그 전용) + 셰이더 글로벌 `candle_0..3`(가까운 4개가 돌에 따뜻한 2단 빛).
- **먼지**: 공중 먼지 GPUParticles(카메라 공간, 난류) + 디딤판이 바뀔 때마다 발밑 일회성 퍼프.
- **림 라이트**: 탑 우측 가장자리 푸른 림(`rim_amount`). **깃발**: 탑 정면 붉은 문장 깃발(한 바퀴마다).
- **후처리**: Glow(softlight), Adjustments(밝기 1.18·대비 1.05·채도 1.06), 가장자리 보라 틴트 + 하단 비네트, 대쉬 모션 블러.
- **대쉬 속도 곡선**: `dash_curve(t)` = smoothstep 가속(0~0.14s) → 홀드 → smoothstep 감속(0.30~0.62s), 최대 1.85x. 블러 강도도 같은 곡선.

## 연출
- **검 궤적**: `shaders/slash_trail.gdshader` — 레퍼런스 `reference/slash_ref.png` 에서 샘플링한 색(코어 #f6f7fb, 테두리 #8ca3ef)과 두께(화면폭 ~22%)의 렌즈형 초승달; 코어 34% / 테두리 86% / 바깥 글로우 3단 밴드, 꼬리는 얇게. + `MeshBuilder.crescent()`. 공격별 초승달 메시(평면·각도·반경은 `character.gd` 의 `TRAILS`)가 스매시 프레임에 나타나 3프레임(12fps) 동안 꼬리부터 단계적으로 사라진다. 알파 3단 양자화 + 바깥 테두리 잉크선.
- **공기 원근법**: `toon_stone.gdshader` 의 `fog_*` 유니폼(카메라 거리 30→95 에서 최대 42% 를 `FOG_COLOR` 로). 캐릭터 머티리얼(`character_mat`)은 `fog_enabled=false` 로 제외되어 항상 또렷하다. 원경 첨탑은 `spires.gdshader` 의 `fog_amount`.
- **대쉬 모션 블러**: 후처리 셰이더의 `blur_amount`(계단 진행 방향 11탭). 런지 동안만 켜지고 끝나면 바로 꺼진다(스텝).
- **계단 끊김**: `STAIR_GAPS`(한 바퀴 기준 계단 인덱스)가 빠진 디딤판. 지상 상태에서 구멍 위에 오면 `fall` 클립(4프레임 낙하) 후 다음 계단으로 복귀. 점프·대쉬 중에는 안전.
- **근접 컬링**: 벽 계단·갤러리·아케이드·종·샹들리에는 월드 회전으로 카메라 앞(z > 17)을 지날 때 숨겨져 화면을 가리지 않는다(`_near_cull`).
- 탑 반경 7.5 / 한 바퀴 46계단 / 피치 18.4 — 디딤판 길이는 유지하면서 회전 각속도를 낮춰 계단이 완만하게 보인다.

## 핵심 구조 (scripts/)
| 파일 | 역할 |
|---|---|
| `main.gd` | 환경·카메라·조명·월드 전체를 절차적으로 빌드. 팔레트 상수와 레이아웃 상수가 맨 위에 있음 |
| `climb_world.gd` | `ClimbWorld` 노드. 자식 전체를 `rotation.y = -phase·2π`, `position.y = base_y - phase·pitch` 로 움직임. 한 바퀴마다 되감아도 나선은 자기 자신과 겹치므로 이음새 없음. `step_transform(i)` 로 i번째 계단 위 위치를 얻어 적·아이템을 배치할 수 있음 |
| `mesh_builder.gd` | 원기둥·나선 계단·회전체(종)·박스 메시 생성. UV 는 월드 단위(호 길이, 높이)라 벽돌이 1:1 로 타일링됨 |

## 텍스처 (textures/)
- `brick_detail.png` — 레퍼런스 탑의 라이트 면(700..1000, 90..420px)에서 추출해 저주파 조명을 제거하고 타일링 가능하게 만든 손그림 벽돌 디테일(회색, 0.5 = 중립). `tools/extract_detail.py` 로 재생성. 셰이더의 `detail_tex`/`detail_tile`/`detail_ink` 로 사용하며, 타일 크기는 둘레와 피치의 정수 분할이어야 한다.

- `grade_lut.png` — 선택적 컬러 그레이딩 LUT(`tools/build_lut.py` 가 렌더→레퍼런스 히스토그램 매칭으로 생성). 돌 색을 틀어 시각적으로는 오히려 멀어져 **기본 꺼짐**이며 `-- --grade` 로만 켜진다.

## 쉐이더 (shaders/)
- `toon_stone.gdshader` — `unshaded` 로 렌더하며 월드 노멀·`light_dir` 유니폼으로 하드 2~3단 밴딩(그림자/라이트/하이라이트)을 셰이더 안에서 직접 계산(엔진 조명을 쓰면 ALBEDO 가 한 번 더 곱해져 팔레트 색이 어긋남). 절차적 벽돌·모르타르·검은 때(grime)·눈(vertex color b), 고딕 창 컷아웃(`windows_enabled`), 계단 아래 아케이드(`arcade_enabled`). `noise_period`/`brick_period` 로 모든 패턴이 피치(14.4) 단위로 정확히 반복되게 맞춰 되감기 이음새를 없앰.
- `outline.gdshader` — 역면(inverted hull) 잉크 외곽선. 매끄러운 메시에 `next_pass` 로 적용.
- `sky.gdshader` — 지평선 핑크 → 마젠타 → 보라 그라데이션.
- `spires.gdshader` — 원경 첨탑 실루엣(회전만 하는 레이어).

## 루프 불변식 (바꿀 때 주의)
- `PITCH = STEPS_PER_TURN × STEP_H` (현재 64 × 0.375 = 24.0). 탑 반경 10.5.
- 벽돌 높이·창 행 간격·체인 링크 간격(0.48×2)·노이즈 주기·디테일 타일은 모두 PITCH 의 정수 분할이어야 함.
- 한 바퀴에 한 번 등장하는 소품(종·샹들리에·갤러리)은 `for t in range(-2, 3)` 로 PITCH 간격 복제.

## 키프레임 리뷰 시트 (`pose_review.html`)

- 캡처: `Godot ... --path . -- --poses=screenshots/poses` → 모든 클립의 키 포즈를 회색 스튜디오 배경(탑·FX 숨김, 클립마다 한 프레이밍)으로 한 장씩 저장 + `poses.json`.
  포즈 플레이어는 `runner.frozen` 으로 멈추고 `apply_key(clip, i)` 로 키를 직접 적용한다(이징·전경 없음).

- 사용: 이미지 위에 드래그해 스케치, 키별·클립별 코멘트. 브라우저에 자동 저장되며 「피드백 내보내기」로 `pose_feedback.json` 을 받는다.
  그 파일을 프로젝트 폴더에 두면 코멘트와 스케치(PNG dataURL)를 읽어 포즈 수정에 반영할 수 있다. 반영한 피드백은 `feedback/` 에 보관.
- 포즈 원칙 (2026-10-28 1차 피드백, `tools/patch_v13.py`): 검은 항상 **이동 방향의 반대**를 가리킨다 — 달리기·대시·점프 도약은 뒤로, 낙하 중(jump/drop/recover/jump2 끝)은 `FALL_ARMS` 로 위로. 2단 점프는 검을 팔과 일직선 스포크로 고정해 끝이 완전한 원을 그린다. 대시(LEAP)는 엉덩이까지 눕히고 한쪽 무릎을 접어 앞으로.
