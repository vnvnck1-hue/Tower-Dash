# 타격 이펙트(Hit Effects) 명세

작성일: 2026-10-28 · 기준 브랜치 `feature/round-skill-hud` · Godot 4.7.2

[적 타격감 기능 명세서](hit-feel-spec.md) 4.5절(VFX)을 **이펙트 하나하나의 모양·시간·색·배치·예산** 수준으로 풀어 쓴 문서다.
판정·히트스톱·카메라·숫자·콤보·사운드는 기능 명세서를 보고, 이 문서는 "화면에 무엇이 어떻게 그려지는가"만 다룬다.
수치는 2026-10-28 코드 기준. 값을 바꾸면 "현재 값" 을 함께 고친다.

관련: [misfitz-hit-vfx.md](misfitz-hit-vfx.md)(레퍼런스 분석) · [moco-vfx-claude.md](moco-vfx-claude.md)(색 체계 도입 기록) · [moco-vfx-claude-handoff.md](moco-vfx-claude-handoff.md)(정확 팔레트) · [ground-break.md](ground-break.md) · [sword-combo.md](sword-combo.md) · [performance.md](performance.md)(풀·캐시)

## 1. 공통 규칙

### 1.1 색 체계
| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 심지 | `#ffffff` (HDR ×1.3, glow 문턱 1.1 을 살짝 넘김) | 모든 버스트 중심 · 검 궤적 앞날 |
| 아군 공격 | `#ff3cbd` 마젠타 (`MocoFX.ATTACK`) | 검 궤적 몸체 · 충격파 · 바닥 원 · moco 버스트 쐐기 |
| 공격 그늘 | `#b72c8f` (`SHADE`) | 궤적 꼬리 · 뒷면 쐐기 |
| 강타 강조 | `#ffe45a` 노랑 (`CRIT_ACCENT`) | moco 강타 주가시 · 콤보 미터 big |
| 지원(드론) | `#35eed7` 민트 (`SUPPORT`) | STUN! · 민트 마름모 조각 · 보호막 |
| 위험(적) | `#ff5268` (`DANGER`) | **적 공격 예고 전용 — 아군 타격 연출에 쓰지 않는다** |
| MISFITZ 근접 | 면 `#f8d2fa` · 테두리 `#ff2ee8` · 베벨 `#c214d6` · 뒤 덩어리 `#9b2cf0` · 파편 `#7f46dc` | 검 · 관통 일격 · 패링 · 기타 |
| MISFITZ 원거리 | 면 `#fff4c4` · 테두리 `#ffd21e` · 베벨 `#e88a00` · 뒤 덩어리 `#ff9a1e` · 파편 `#e0701e` | bullet · laser · missile (`MisfitzHit.RANGED`) |
| 착탄(총) | HOT (1, .93, .62) · AMBER (1, .68, .2) · FLAME (1, .42, .07) · 연기 `#d6b28b` / `#94704f` | `ToonGunFX` 착탄 |

규칙: 붉은 계열은 적의 몫이라 아군 타격에서 뺐다(예전 `Pal.BLADE` 붉은 충격파 → 마젠타). 꼭짓점 색은 `srgb_to_linear()` 를 한 번만 거쳐 넣는다.

### 1.2 시계
| 이펙트 | 시계 | 이유 |
|---|---|---|
| 타격 버스트 · 검 궤적 · 충격파 · 왜곡 · 바닥 파괴 · 잔상 | **게임 시간** (히트스톱에 함께 멈춤) | 멈춘 프레임에 적 몸과 함께 얼어붙어야 "쿵" 이 읽힌다 |
| 피해 숫자 · 콤보 미터 · 임팩트 프레임 · 패링 별빛 | **실제 시간** | 히트스톱 동안에도 정보가 움직여야 하고, 임팩트 프레임은 1~2프레임 단위라 시간 배율에 흔들리면 안 됨 |

### 1.3 배치
- 판정점은 보통 적 몸 **안쪽**이라 그대로 그리면 깊이 검사에 가려진다. 버스트는 공격이 **온 쪽 표면**으로 `폭 × 0.4` 옮기고 카메라 쪽으로 **0.25m** 당긴다(`MocoFX.PULL`, 0.7 은 벽 너머로 튀어나왔고 0.18 은 몸에 가려졌다).
- 보스는 자체 `fx_point` 가 이미 겉면이라 옮기지 않는다.
- 긴 가지·주가시는 **표면 밖(공격이 온 쪽)** 을 향한다. 진행 방향은 적 몸 속이라 보이지 않는다.
- 바닥에 그리는 것(충격파 · 바닥 원 · 바닥 파괴)은 `Main.gy(pos)` 위 0.02~0.05m.
- 흐르는 씬(추격전 `WorldFlow`)에서는 `FX._add(n, pos, flow)` 로 도로 속도만큼 흘려 보내고, 바닥 파괴는 생략한다.

### 1.4 예산과 재사용 (늘리면 안 되는 것)
| 항목 | 상한 | 방식 |
|---|---|---|
| 타격 버스트 | 동시 **24** (`MocoFX.MAX_BURSTS`), 같은 적 **45ms** 안 재발생 무시 | 노드 하나의 `ImmediateMesh` 에 매 프레임 다시 그림 — 타격마다 노드·재질·텍스처·정적 캐시 없음 |
| 피해 숫자 | 24 (`DamageLog.MAX`), 대상당 6 | Control `_draw` 하나 |
| 스파크(GPUParticles) | 풀 **48** (`FX.PARTICLE_POOL_MAX`) | `FX.burst_particles`, 재질은 색·속도를 양자화한 키로 캐시 |
| 잔상 | 파츠 **900** (`GhostPool.MAX_PARTS`) | 노드·재질 재사용, 흐려짐은 전역 셰이더 값 `ghost_clock` |
| ToonGunFX 조각 | 재사용 풀 600 | `_free` |
| 탄피 / 벽 파편 | 200 / 160, 수명 16 / 11초 | `GunFX` |
| 처치 잔해 | 220 조각 | `Debris` 풀 |
| 바닥 파괴 | 조각 460 · 연출 30 · **초당 5회** | `GroundBreak` |
| 셰이더 | `ResCache.shader(code)` 로 코드 문자열당 1개 | 씬마다 재컴파일 금지 |

첫 타격의 셰이더 컴파일·텍스처 굽기 끊김은 `FxWarm`(씬 시작 때 플레이어 발밑 25m 아래에서 4프레임 동안 한 번씩 써 봄)이 흡수한다.

## 2. 타격 버스트 (적 몸 위 "맞았다" 표식)

진입: `HitSpark.spawn(pos, dir, k, enemy, heavy, source)` → `MocoFX.hit` → 스타일에 따라 `MisfitzHit.make`(기본) 또는 moco 별.
크기 계수 k: source 별 slash/phantom 1.8 · missile 1.5 · parry 2.0 · laser 0.8 · 그 외 1.0, 하한 `1 + 0.08·dmg`. 대상 폭 w 는 `radius × 2` 를 0.8~2.2m 로 자름.

### 2.1 MISFITZ 별 (기본, `misfitz_hit.gd`)

레퍼런스는 정지 1장(정점 A · 소멸 B)이라 사이 시간표는 직접 설계. 60fps 프레임 기준.

| 시간 | 프레임 | 그려지는 것 |
|---|---|---|
| 0 ~ 0.033 (`T_POP`) | 0~1 | 별이 0.55 → **1.12배**로 튀어나오며 흰색 → 테두리색. 흰 섬광 원. 광채 켜짐(`smoothstep(0, .04)`) |
| 0.033 ~ 0.10 (`T_A`) | 2~6 | **정점 A**: 1.12 → 1.0 → 1.06배. 골 반경 0.25(두툼한 가지). 잔상 2겹(반경×0.14·i 뒤로, α .72/.55, 0.02~0.035 에 켜져 0.08~0.115 에 꺼짐). 뒤 덩어리(크기 r×1.22, α .82, 0.012 ~ 0.13). 광선 4개(길이 1.25~1.65r, α .8, 0.015 ~ 0.16). 네모 픽셀 11개 흩어짐 |
| 0.10 ~ 0.17 (`T_B`) | 6~10 | 골이 0.25 → **0.035** 로 파고들어 가는 선 가지만 남음(`smoothstep(.08, .17)`). 뒤 덩어리 → 속 빈 윤곽 파편 3개(ㄱ자 · 삼각형 · 사다리꼴+가시)로 깨져 바깥으로(`t > 0.088`) |
| 0.17 ~ 0.30 (`T_END`) | 10~18 | **소멸 B**: 1.06 → 0.7배, 별 알파 `1 − smoothstep(.22, .30)`. 파편·픽셀 흩어지며 사라짐 |

- 별 모양 `ARMS`: 3갈래 비대칭 — 각 0 / 1.88 / 3.70 rad, 길이 1.0 / 1.0 / 0.62. 긴 두 가지의 가운데(0.94 rad)를 표면 밖으로 돌리고 좌우 무작위 반전.
- 반경 r = w × **0.4** (`R_NORMAL`, 레퍼런스 0.8 의 절반 — 사용자 요청) × `lerp(1, 1.12, kk)`. 강타 r = w × 0.52.
- 층 구성(안 → 밖): 흰 심지 ×0.56 · 연한 면 ×0.86 · 테두리 ×1.0, 가지 한쪽 면은 베벨색.
- 픽셀 조각: 크기 0.035~0.12, 18% 는 ×1.6, 시작 지연 0~0.08, 수명 0.18~0.3 (×ts).
- **강타**: 시간 ×1.25 (`HEAVY_TIME`) · 크기 ×1.3 (`HEAVY_SIZE`) · 잔상 3겹 · 픽셀 16개.
- 톤: `RANGED`(bullet · laser · missile) → yellow, 나머지 → purple.

### 2.2 moco 별 (대안, `--hitfx=moco`)
| | 일반 | 강타 |
|---|---|---|
| 지름 | w × 0.75~0.9 | w × 1.2~1.6 |
| 별 | 6각 비대칭(한 꼭짓점 1.7배) | 8각(1.7 · 반대쪽 1.35) + 노란 주가시 1.3 (60% 확률로 0.85 하나 더) |
| 쐐기 | 마젠타 3 (첫 쐐기 길이 1.0, 나머지 0.55~0.78) + 짙은 뒷면 쐐기 1.18 α.9 | 4 |
| 조각 | 민트 마름모 3~4 | 마젠타·노랑 파편 4~6 |
| 시간 | 심지 70ms · 큰 면 150ms · 소멸 220ms | 70 / 160 / 300ms |
| 펼침 | 0.05초 cubic | 〃 |

### 2.3 예전 방추 (`--vfx=old`, `hit_spark.gd`)
ToonGunFX SPINDLE 조합, 크기 `s = √k`: 비행접시 0.09s (1.7×1.5)s ORANGE · 안쪽 방추 0.06s AMBER · 잔물결 0.1s(지연 .035, grow 5) · 관통 방추 0.07s · 불똥 4~6개 0.11~0.17s 속도 6~9. PULL 0.7. 재질이 색·크기 키로 캐시돼 재로딩마다 늘던 것이 MocoFX 로 바뀐 이유.

### 2.4 확인
허수아비 씬 **8** 스타일 전환 · **Shift+8** 버스트만 0.2배속(`MocoFX.slow`, 판정 무관). 캡처 `_capture/misfitz_hit_show.gd` → `output/misfitz-hit-20261006/`(총 노랑 · 미사일 노랑 강타 · 검 보라 강타 20프레임씩).

## 3. 착탄 이펙트 (기본총, `GunFX.impact_body` → `ToonGunFX.impact`)

| 조각 | 모양 | 수명 | 크기(×k) | 색 |
|---|---|---|---|---|
| STAR | 4갈래 섬광, 흐린 가장자리 | 0.07s | 1.05 | HOT, 밝기 3.0 |
| RING | 울퉁불퉁한 구름 테두리 고리 | 0.15s | 1.3 | (1, .72, .36, α.7) |
| PUFF ×2 | 구름 연기, 부풀었다 안쪽부터 먹혀 초승달 → 소멸 | 0.48s / 0.4s | (1.3, 1.2) / (0.8, 0.75), 지연 .02 / .05, drag 4 | 연기색 ↔ 몸체색 30% 혼합 |
| CROWN | 왕관 불꽃: 가시 → 덩어리 → 아래가 파여 아치 → 갈고리로 흩어짐 (9프레임) | 0.32s | (0.82, 1.0) | FLAME, 1.8 |
| SHARD ×2~3 | 톱니 파편 | 0.1~0.16s | 속도 5~8, drag 9 | |
| `_spray` | 불똥 4k | 0.18s | 35°, 속도 8 | SPARK_COLORS fffbe0 / ffd23a / ff8a1a |
| 부스러기 | 1~3k 개, 60% 몸체색 · 40% `#5a1428` | 바닥 낙하 | 수평 1.5~3 · 수직 2~4 | |

- 착탄점은 `pos − fwd×0.1`, 방향은 `−fwd`(공격 온 쪽). 모양별 카메라 당김 `PULL` = STAR .9 · ARROW .2 · SHARD .3 · RING .6 · PUFF .5 · CROWN .7 · SPINDLE .1.
- 보스전·스트림 씬은 카메라가 멀어 `ToonGunFX.view_k` **1.6**(`BossMain.VIEW_K`)으로 전부 키운다. 맘모스는 판정점이 차체 안이라 `fx_point` 로 겉면에 그린다.
- 벽 착탄 `impact_wall`: 불똥 4k / 55° / 속도 9 / 0.2s + 회색 파편 2~4k.
- 총알 자체의 `bullet_hit`(FX): 흰 플래시 .55 / .07s + 스파크 6.
- 탄피 `eject`: 원기둥 r .042~.046 h .17, 밖 2.2~3.6 · 위 3.0~4.6 m/s, 회전 14~26, 바닥 닿을 때 `tink` −15dB.

## 4. 광선검 궤적과 베기 이펙트

### 4.1 호 메시와 셰이더 (`fx.gd:86-140`)
- 메시 `_build_arc_mesh(0.45, 2.7, 150°, 28)`: 안 반지름 0.45 · 밖 2.7m · 150° · 28분할. 모든 궤적·초승달이 이 메시 하나를 공유하고 `progress` 인스턴스 값으로 그어진다.
- mo.co 분기(`moco = true`):
  - 길이 `mlen = mix(0.85, 1.0, heavy)`, 앞날 `mhead = progress / 0.72` — 휘두름 끝(0.72)에 앞날이 호 끝에 닿고 그 뒤 꼬리가 빠져나간다.
  - 두께 `mix(0.19, 0.29, heavy)` × `sin(u·π)` — 호 밴드의 **바깥쪽만** 속 빈 초승달로 남김. 보이는 호 일반 약 128° · 강타 150°.
  - 색: 꼬리 `m_shade` → 몸체 `m_attack`(50% 지점) → 가장자리·머리 쪽 `m_core × 1.2`.
  - 알파 `clamp(al·2.2) × (1 − smoothstep(.72, 1, progress))`.
- 예전 분기: `deep` → `light` 그라데이션 ×1.35, 머리 `progress × 1.45`, 길이 0.62.

### 4.2 `FX.slash(owner, yaw, style)` — 한 타의 궤적 (`fx.gd:493`)
| style | 구성 |
|---|---|
| 0 / 1 | 가로 호 1개(1 은 좌우 반전), swing 0.05s |
| 2 내려찍기 | 호를 세워(BACK 축 90°) 위 → 아래, (0.9, 1, 1.1) 배율, heavy. 앞 2.2m 바닥에 **충격파 2.2 / 0.25s / 두께 .07** + 스파크 14(흰 · 마젠타 · 그늘, 속도 7, 0.35s, 중력 −12) |
| 3 회전 베기 | 호 3개를 120° 간격 · 0.033s 시차로, (1.05) 배율, heavy. 발밑 **충격파 3.2 / 0.28s / .06** |

- 모든 style 공통: 발밑 **바닥 원** 반경 1.9 · 높이 .01 · 마젠타 α.1(예전 붉은 α.12) → 0.2s 페이드.
- 호 1개 `_slash_arc`: `progress` 0 → 0.72 를 **swing** 초(0.045~0.06)에, 0.72 → 1 을 꼬리 **0.07s / 강타 0.13s**(예전 0.4s)에 ease-out. 전체 일반 약 120ms · 강타 약 180ms.

### 4.3 초승달 `FX.crescent(pos, basis, swing .035, life .11)`
콤보 다단히트(선풍 7타 등)마다 몸 둘레 가로 초승달. 같은 호 메시, `deep` (0.42, 0.12, 0.95) 보라 · `light` (1, .82, .95) 분홍, EXPO ease-out 으로 0.035s 에 그어지고 0.11s 안 사라짐. 선풍은 각도 ±0.4 · 기울기 ±0.25 무작위, (1.25, 1, 1.25) 배율.

## 5. 관통 일격 일섬 (`FX.phantom_cut`, `fx.gd:577`)

## 6. 바닥 충격 계열

### 6.1 충격파 `FX.shockwave(pos, c, size, dur .35, thick .08)`
토러스 고리를 (0.2, thick, 0.2) → (size, thick×0.3, size) 로 cubic-out 확장, 색은 `c` → `Pal.FLOOR` 로 바래며 사라짐. 밝기 1.3. 바닥 +0.04m.

### 6.2 왜곡 `Distortion.burst(pos, radius, dur .4, strength 1, haze 0)`
화면 공간 굴절 쿼드(radius×2). 앞머리 `mix(0.06, 0.92, 1−(1−t)³)`, 폭 `mix(0.1, 0.22, t)`, 굴절 **22px**(800px 높이 기준) · 색수차 2.5, `smoothstep(.55, 1)` 페이드. render_priority 최소+1. 게임 시간이라 히트스톱에 멈춤. `FluidSmoke.blast` 를 함께 불러 유체 연기를 밀어낸다.

| 호출 | radius | dur | strength |
|---|---|---|---|
| 칼끝 적중 | 1.3 | .22 | .8 |
| 검 강타 | 3.2 | .3 | 1.2 |
| 6타 착지 | 4.6 | .38 | 1.4 / 1.0 |
| 지연 참격 끝 | 3.0 | .3 | 1.2 |
| E 내려찍기 | 3.6 (반경 3 × 1.2) | .32 | 1.4 |
| 휠윈드 시작 | 2.6 | .28 | 1.1 |
| 폭발 `fire_explosion` | BASE_R·k·2.4 | .4 + .12√k | .7~1.6, haze 1 |

### 6.3 바닥 파괴 `GroundBreak.burst(pos, power, dir)` ([ground-break.md](ground-break.md))
| 스타일 | 수명 | 내용 |
|---|---|---|
| **crumble** (기본) | 2.7 | 구멍 + 가장자리 작은 판(×0.55) + 파편 |
| slab | 2.4 | 방사형 3고리 × 7~9 판이 바깥 모서리 경첩으로 52~80° 들림, 틈은 어두운 금 |
| spike | 1.7 | 각진 끌 기둥이 기울어 솟았다 들어감 |
| buckle | 2.6 | 극좌표 바닥 면이 물결 → 주름 둔덕 고리(정점 색 명암 과장) |
| scatter | 2.9 | 튀고 구르다 멈추는 덩어리 + 별 구멍 |
| mix / off | 2.6 / — | |

- 조각 재질 = 그 자리 바닥 ShaderMaterial 복제 × 밝기 1.32 · 그림자 .62 (인스턴스 캐시).
- 세기 0.05~1.5 로 자름. 호출: E 내려찍기 **1.0** · 검 강타 **0.55** · 미사일 **0.3** · LANCASTER 0.42~1.25. 효과음 `clank` 저음(피치 .42~.55, 볼륨 −9 + 4·min(power,1) dB).
- 돌진·휠윈드가 지나간 자리 `trail_mark`: 높이 ×0.38 작은 찌그러짐 + 파편 3 + 짧은 금, 1.7s, 초당 14, 공중 제외.
- 허수아비 **=** / **Shift+=** 스타일, **F4** 조준점 미리보기, `--ground=id`.

### 6.4 레이저 바닥 그을음
`FX.laser` 의 바닥 그을음은 `WorldFlow.GROUND`(80) 로 흐른다. 폭발 그을음 `StylizedExplosion._scorch_z` 는 도로 속도만큼 앞서 간다.

## 12. 미결·주의

1. `_heavy_hit`(강타 바닥 파괴·충격파) 은 콤보 표에 `"heavy": true` 가 없어 **실제로 안 나온다**. 6타에 켤지 결정 필요(기능 명세서 8절).
2. 반투명 빌보드에 `depth_draw_always` 를 쓰면 네모로 뚫려 보인다(휠윈드 소품에서 발생) → `depth_draw_never`.
3. 새 셰이더에 조명 풀을 쓰면 `#define pool_on/pool_pos` 와 점광원 경로(`LIGHT_IS_DIRECTIONAL` 분기)를 유지할 것(브롤 룩 기록).
4. `Sfx "boost"` · `"beam"` 은 loop 라 단발 이펙트음으로 쓰지 말 것.
5. 패링 효과음 후보 v5 는 사용자 선택 대기.
6. 색 상수가 `MocoFX`(mo.co 체계)와 `MisfitzHit.PALETTES` 두 곳에 있다. 통합하려면 두 스타일의 톤 분기(근접/원거리)를 유지해야 한다.
